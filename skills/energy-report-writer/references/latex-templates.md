# Document Structure and LaTeX Templates

<!-- Adapted from databricks-industry-solutions/vital-skills (skills/report-builder/references/report-structure.md); modified for the energy industry. -->

Two LaTeX templates plus a Markdown brief, and section-by-section guidance for energy documents
generated from notebook work. Type-specific outlines (reliability annual report, rate-case
exhibit narrative, regulatory form commentary, ESG disclosure, reserves / production summary)
are in `energy-report-types.md`; they slot into the templates below.

## Template choice

| Template | When to use | Style |
|---|---|---|
| **Technical study** (default) | Engineering studies, regulatory narrative support, disclosure drafts | `article`, numbered sections, booktabs, Sources-of-figures appendix |
| **Internal brief** | Quick team summary, operations review, weekly performance note | `article`, fancyhdr, bullet-led, 2-4 pages |
| **Markdown brief** | Content for a dashboard, Genie space description, wiki, or email | Markdown with `{{fact:id}}` references |

If in doubt, use **Technical study**.

## The rules every template follows

1. **No bare numbers.** Every figure is `\fact{<id>}` (LaTeX) or `{{fact:<id>}}` (Markdown) and
   comes from the facts ledger (`number-traceability.md`). `scripts/check_report.py` renders the
   values and fails on any untraced number.
2. **Notice box on page 1.** Wording below; required phrases are checked by `check_report.py`.
3. **Units in every table header and axis label.** `MW`, `MWh`, `bbl/d`, `Mcf/d`, `boe`,
   `tCO$_2$e`, `min/customer`. State conversion factors (boe at 6 Mcf/bbl energy-equivalent, GWP
   set) in Methods.
4. **Decisions and standards in Methods.** Every decision recorded in the upstream skill's run
   manifest (MED method, b-factor bound, emission-factor vintage, weather station, interval
   convention) is stated in prose with its value (as a fact) and the governing standard.
5. **Sources of figures appendix.** Generated with `ledger_appendix()`; lists each fact, its
   value, and its source table / manifest.

### Required notice (all types)

```latex
\begin{center}
\fbox{\parbox{0.92\textwidth}{\small
\textbf{Draft for review.} This document was generated by Genie Code from analysis notebooks and
requires review by a qualified <<ROLE: engineer | reliability engineer | reserves evaluator |
sustainability lead>> before it is shared. It is not legal, regulatory, or investment advice.
<<EXTRA_NOTICE>>}}
\end{center}
```

`<<EXTRA_NOTICE>>` by type:

| `--report-type` | Extra notice text (must appear) |
|---|---|
| `reserves-production-summary` | "This is not a reserves report. Volume classification under SPE-PRMS or SEC rules requires a qualified reserves evaluator; figures here are production and decline-analysis outputs only." |
| `esg-disclosure` | "Emissions figures are estimates calculated with the factor versions stated in Methods and have not been assured." |
| `rate-case-exhibit` | "Testimony and exhibit sponsorship belong to the utility's witnesses; this draft supports their narrative only." |
| others | none |

## Template 1: Technical study (default)

```latex
\documentclass[11pt,letterpaper]{article}

\usepackage[margin=1in]{geometry}
\usepackage{graphicx}
\usepackage[hidelinks]{hyperref}
\usepackage{amsmath,amssymb}
\usepackage{booktabs}
\usepackage{enumitem}
\usepackage{xcolor}
\usepackage{caption}
\usepackage{float}
\usepackage{microtype}

% Breakable monospace paths: \fpath{} with \allowbreak after / - _ @ (latex_utils.fpath builds these)
\newcommand{\fpath}[1]{{\ttfamily\hyphenpenalty=50\exhyphenpenalty=50%
  \tolerance=9999\emergencystretch=3em #1}}
\newcommand{\todo}[1]{\textcolor{red}{\textbf{[TODO: #1]}}}
% Unrendered facts show up loudly; check_report.py replaces \fact{id} before compiling.
\newcommand{\fact}[1]{\todo{unrendered fact #1}}

\title{<<TITLE>>}
\author{<<AUTHOR_NAME>> \\ \small <<ORGANIZATION_OR_TEAM>>}
\date{<<REPORTING_PERIOD>> \\ \small Draft of \today}

\begin{document}
\maketitle

<<REQUIRED NOTICE BOX — see above>>

\begin{abstract}
<<150 words or fewer: question, data, approach, headline result with \fact{} references.>>
\end{abstract}

\section{Scope and Context}
<<2-3 paragraphs: asset base or service territory, period, why the study was done, which
  standard or filing it supports.>>

\section{Data}
<<PROSE: every source table (\fpath{} for long names), row counts, time range, timezone and
  interval convention, units as received, quality flags and how they were handled.>>

\section{Methods}
<<PROSE: every decision with its value and the governing standard; steps considered but
  rejected; conversion factors; software and skill versions; run-manifest ids.>>

\section{Results}
\subsection{<<Finding 1 — a statement about the system, not a pipeline step>>}
<<2-4 sentences with \fact{} references. Reference the figure.>>

\begin{figure}[H]
  \centering
  \includegraphics[width=0.85\textwidth]{<<FIGURE_FILENAME>>.pdf}
  \caption{<<What is plotted, axes with units, and the takeaway.>>}
  \label{fig:<<LABEL>>}
\end{figure}

\section{Discussion}
\begin{itemize}[leftmargin=*]
  \item <<INTERPRETATION — flagged for the engineer to confirm>>
\end{itemize}
\subsection{Limitations}
\begin{itemize}[leftmargin=*]
  \item <<DATA GAPS, ASSUMPTIONS, SENSITIVITY TO DECISIONS>>
\end{itemize}

\appendix
\section{Sources of Figures}
<<OUTPUT OF ledger_appendix(ledger, used_ids)>>

\section{Software and Run Manifests}
\begin{tabular}{llll}
\toprule
Package & Version & Package & Version \\
\midrule
<<PKG>> & <<VER>> & <<PKG>> & <<VER>> \\
\bottomrule
\end{tabular}

<<Run manifest ids / paths for every upstream skill run, with \fpath{}.>>

\end{document}
```

### Section guidance

- **Results = statements about the system.** "Feeder 1204 accounts for a fifth of non-MED
  customer minutes" belongs in Results; "Outage records were deduplicated" belongs in Data.
- **Methods = the agent's primary deliverable.** Full prose, every parameter woven in. Example of
  sufficient detail:
  > Daily SAIDI was computed per IEEE Std 1366 from sustained interruptions. Major Event Days
  > were identified with the 2.5β method using the five prior years of daily SAIDI, giving a
  > threshold T_MED of \fact{tmed_2025}; \fact{med_count_2025} days exceeded it and were excluded
  > from the reported indices but are shown separately in Figure~2.
- **Discussion is bullet-form.** The agent flags patterns; the engineer or analyst writes the
  interpretation. Ask before writing extended interpretation.
- **Software versions are resolved programmatically** with `importlib.metadata.version()`;
  include upstream skill names and versions from run manifests.

## Template 2: Internal brief

```latex
\documentclass[11pt,letterpaper]{article}
\usepackage[margin=0.9in]{geometry}
\usepackage{graphicx,booktabs,enumitem,xcolor,float,fancyhdr,microtype}
\usepackage[hidelinks]{hyperref}
\newcommand{\todo}[1]{\textcolor{red}{\textbf{[TODO: #1]}}}
\newcommand{\fact}[1]{\todo{unrendered fact #1}}
\pagestyle{fancy}\fancyhf{}
\fancyhead[L]{\small\textit{<<SHORT_TITLE>>}}\fancyhead[R]{\small\textit{<<PERIOD>>}}
\fancyfoot[C]{\thepage}

\title{<<TITLE>>}\author{<<AUTHOR>>}\date{\today}
\begin{document}\maketitle

<<REQUIRED NOTICE BOX>>

\section*{Headlines}
\begin{itemize}[leftmargin=*]
  \item <<HEADLINE with \fact{} reference>>
\end{itemize}

\section{What changed}   % bullets with \fact{} references
\section{Why}            % drivers, each traceable to a table
\section{Method notes}   % decisions + standards, one line each
\section{Next steps}     % owners and dates

\appendix\section{Sources of Figures}
<<ledger_appendix(...)>>
\end{document}
```

## Figures

Save every figure as **PDF and PNG** (300 dpi) from the notebook; reference the PDF in LaTeX.
Energy chart conventions are in `energy-figures.md`. Captions state what is plotted, axes with
units, and the takeaway.

| Notebook pattern | Where the figure is |
|---|---|
| `plt.savefig("path")` / `fig.savefig` | The path given |
| `fig.write_image("path")` | Plotly export path |
| `display(fig)` / `plt.show()` | Not a file: add a cell that saves PDF + PNG |

## Tables

`booktabs` only (`\toprule`, `\midrule`, `\bottomrule`). Units in the header (`SAIDI (min)`), not
in cells. Right-align numbers. Cells hold `\fact{}` references, not literals.

## LaTeX special characters

Use `latex_utils.latex_escape()` for any prose copied from notebooks or tables:
`_ % & # $ { } ~ ^ \`. Table and column names go in `\texttt{}` with `_` escaped, or `fpath()`
for long paths.
